## Cookies and analytics

The site includes:

- `Accept analytics`, `Decline` and `Manage cookies` controls.
- First-party `codevalanche_consent` cookie with a one-year expiry.
- No analytics script before explicit acceptance.
- GA4 adapter that can track page views and limited non-sensitive interactions.
- No source code, prompts, query strings, form data, account data or browsing history sent to analytics.
- Privacy and Terms pages describing the current behavior.

Analytics is not collecting yet. The existing Google Analytics property visible in the account was for `Flood-It!`, so it was deliberately not reused for Codevalanche. When a Codevalanche GA4 web stream exists, replace the placeholder measurement ID in the inline configuration near the bottom of `src/index.html`:

```js
window.CODEVALANCHE_ANALYTICS = { measurementId: "G-XXXXXXXXXX" }
```

Do not paste a secret into the site. A GA4 measurement ID is public configuration, but the correct Codevalanche property still needs to be created or selected deliberately.
